# Kopi Pojok: Landing Page UMKM

Landing page satu halaman untuk warung kopi fiktif **Kopi Pojok**. Dibuat sebagai contoh portofolio jasa pembuatan website untuk UMKM.

🔗 **Demo:** https://mustaghfirly.github.io/kopi_pojok/

## Fitur

- Hero dengan ajakan pesan langsung lewat **WhatsApp** (pesan sudah terisi otomatis)
- Daftar menu bergaya struk, mudah diganti harganya
- Galeri foto tempat
- Informasi alamat, jam buka, dan kontak
- **Responsif**: nyaman dibuka di HP maupun laptop
- **Mode terang dan gelap** mengikuti pengaturan perangkat

## Teknologi

- HTML5
- CSS3 (CSS variables, Grid, Flexbox)
- Google Fonts (Bricolage Grotesque)
- Tanpa framework, tanpa JavaScript

## Struktur Folder

```
kopi-pojok/
├── index.html
├── style.css
└── img/
    ├── meja.webp
    ├── uno.webp
    └── malam.webp
```

## Cara Menjalankan

1. Clone repository:
   ```
   git clone https://github.com/mustaghfirly/kopi-pojok.git
   ```
2. Buka folder `kopi-pojok`.
3. Buka `index.html` di browser, atau pakai ekstensi **Live Server** di VS Code.

## Menyesuaikan untuk Usaha Lain

Template ini bisa dipakai ulang untuk kafe, laundry, barbershop, dan usaha kecil lainnya. Yang perlu diganti:

- Nama usaha, alamat, dan jam buka di `index.html`
- Nomor WhatsApp (format `62...` tanpa angka 0 di depan)
- Daftar menu atau layanan beserta harganya
- Foto di folder `img`
- Warna utama di bagian `:root` pada `style.css`

## Catatan

Ini adalah proyek contoh. Nama usaha, alamat, dan nomor telepon di dalamnya fiktif.
